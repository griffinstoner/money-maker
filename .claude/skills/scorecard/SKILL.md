# Weekly scorecard

1. Ask for this week's outreach sent, replies, calls, closes and revenue, unless the user already gave them. If Zendrop is in use, pull orders and revenue from it instead of asking.
2. Add a row to `jarvis/scorecard.md` for the week (Monday's date).
3. Find the weakest step in the funnel (outreach → replies → calls → closes → revenue), compared with last week and with reasonable rates: about 5–15% reply rate on personalised outreach, about 20–40% of calls closing. Put it in the "Number to fix" column.
4. Give one specific change that would fix it this week. Then commit and push.
5. End with **"Your next action (under 1 hour):"**.
