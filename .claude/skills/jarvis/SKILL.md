# Daily briefing

1. Read `jarvis/profile.md`, `jarvis/scorecard.md` and the top of `jarvis/log.md`. If the profile still has `[unfilled]` fields, run the first-run questions from `CLAUDE.md` instead of a briefing.
2. If the plan involves dropshipping, or any Zendrop store exists, check Zendrop (load its tools with ToolSearch): unfulfilled or stuck orders, open order issues, and last week's performance. Read-only. Don't change anything without asking.
3. Reply with these sections, kept short:
   - **Where we are:** day X of 30, revenue so far vs. the $1,000 target, and the current stage in `PROMPT.md`.
   - **Needs attention:** anything overdue, stuck orders, prospects waiting on a reply. Write "Nothing" if there's nothing.
   - **Today's top 3:** specific tasks that fit the user's hours, each with a measurable target.
4. End with **"Your next action (under 1 hour):"**.
